# Security Policy

## Supported versions

TalonHound is currently in **Beta** (`0.1.0-beta.x`).

Security fixes are prioritized for the latest published Beta release on the `main` branch.
Older prerelease builds may not receive backports.

## Reporting a vulnerability

**Do not open a public GitHub issue for undisclosed security vulnerabilities.**

Prefer GitHub's private vulnerability reporting for this repository (Security → Report a vulnerability), once that feature is enabled on the public project.

If private vulnerability reporting is not yet available, contact the maintainers through a private channel listed on the GitHub organization or repository profile. Do not include exploit details in public discussions.

## What to include

Please include as much of the following as you can:

- Affected TalonHound version (`VERSION` / Administration → Settings)
- Deployment mode (installer / Docker Compose source build)
- Description of the issue and potential impact
- Steps to reproduce (proof-of-concept if available)
- Whether a fix or workaround is already known

## Response expectations

Maintainers will acknowledge valid reports as soon as practical. Beta cadence means response times can vary; there is no guaranteed SLA. Please allow reasonable time before any public disclosure.

We appreciate responsible disclosure that protects operators running TalonHound.
