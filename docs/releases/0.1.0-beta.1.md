# TalonHound v0.1.0-beta.1

First public beta of TalonHound — a self-hosted threat intelligence and IOC management platform.

## Highlights

- IOC and threat-feed management with scheduled imports
- Published threat feeds for outbound distribution
- Enrichment provider integrations
- IOC correlation and search
- Administration, RBAC, and system settings
- Docker Compose deployment for fresh installs and upgrades
- Informational update checks via trusted channel manifests

## Beta notice

This is a beta release. Review the deployment and backup documentation before upgrading production environments.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.0-beta.1`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
