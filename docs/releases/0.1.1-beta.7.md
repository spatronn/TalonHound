# TalonHound v0.1.1-beta.7

Bug-fix beta packaging the latest MCP correctness and consistency fixes.

## MCP Improvements

- **`get_ioc_context` enrichment completeness.** Context now returns the provider-specific intelligence that already exists for an IOC — RDAP/WHOIS, AbuseIPDB and IPinfo Lite — alongside VirusTotal, matching what the IOC Details view shows. Enrichment applicable to the IOC type is included when stored; a provider is listed only when a result exists.
- **`bulk_lookup_iocs` classification consistency.** Bulk results now use the same effective classification resolution as `lookup_ioc` and `get_ioc_context`, so classifications are consistent across all three MCP tools.
- **No more `unknown` classification leakage.** Legacy `unknown` values no longer surface in bulk lookup results, and multi-select classifications resolve correctly.
- **Batch-safe resolution.** Classification lookups for a batch are resolved in a constant number of queries (no per-IOC query growth).

## Reliability

- Added regression coverage for enrichment-provider completeness and MCP classification parity across the single-IOC and bulk lookup tools.

## Notes

- This is a beta prerelease.
- No database migration is introduced by this release (latest migration is unchanged from v0.1.1-beta.6).
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.7`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
