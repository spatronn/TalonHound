# TalonHound v0.1.1-beta.8

Bug-fix and UX beta covering VirusTotal not_found message correctness across API/UI/MCP, plus IOC Details Copy success feedback.

## Fixed

- Fixed VirusTotal `not_found` enrichment messages incorrectly referring to URLs for file hashes and other IOC types.
- Fixed MCP/API inconsistency where stale VirusTotal DB messages could appear through `get_ioc_context`.
- Legacy VirusTotal `not_found` records are now normalized on read without requiring a database migration.
- Fixed IOC Copy feedback timer behavior discovered during pre-release smoke testing.

## Improved

- Centralized VirusTotal type-aware `not_found` message handling across API, UI, and MCP enrichment aggregation.
- IOC Details Copy button now shows a temporary success Check after a successful clipboard operation.
- Added regression coverage for VirusTotal IOC mappings, stale MCP enrichment messages, and clipboard success feedback.

## Compatibility

- No database migration required.
- Existing enrichment data remains compatible.
- `Check again` persists corrected VirusTotal text.
- No API contract changes.

## Notes

- This is a beta prerelease.
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.8`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
