# TalonHound v0.1.1-beta.10

Analyst-experience beta bundling three UX/enrichment improvements. No database migration, no API contract changes.

## Added / Improved

### IOC navigation (Search & Watchlist)
- IOC values in IOC Search results and the Watchlist are now real browser links.
- Normal click still opens the IOC detail in the current tab; middle-click, Ctrl+Click (Windows/Linux), Cmd+Click (macOS), and the right-click context menu now behave like any web link — so analysts can open several IOC details in separate tabs and keep the results page open.
- Links are not forced to open in a new tab; opening in a new tab stays the analyst's choice. Watchlist star (add/remove) behavior is unchanged and independent of navigation.

### VirusTotal File Information enrichment
- Trusted technical file metadata learned during VirusTotal enrichment can now populate **empty** File Information fields — known hashes (MD5 / SHA1 / SHA256), file type, MIME, IMPHASH, TLSH, and SSDEEP.
- Existing canonical metadata is preserved: a value already provided by the ingesting source (e.g. AlienVault OTX, MalwareBazaar), an analyst, or another provider is never overwritten.
- The original IOC ingestion source/provenance is unchanged — VirusTotal remains an enrichment provider, not the source.
- Observed VirusTotal file names are shown as **Observed File Names** (uploader-supplied observations), never as the one authoritative filename.
- Alternate MD5/SHA1 hashes are shown as known identifiers for the same file; no new IOC records are created for them.

### Custom Threat Feeds UI
- The Custom Threat Feeds page now uses the same visual and operational presentation as the main Feeds dashboard: summary cards (Total / Enabled / Needs Attention / Running / Queued), a compact operational table (Feed / State / Last Run / Last Result / Schedule / Actions), consistent badges, buttons, and spacing.
- Lower-priority configuration (URL host, format, IOC type, confidence, expiration) is now a compact secondary line under the feed name, keeping it accessible without a dense wide table.
- Status and last-result presentation is clearer; long provider errors no longer distort the table. All existing actions (Run now, Edit, Delete) and the delete confirmation are preserved.

## Compatibility

- **No database migration required.** No schema or data changes.
- No API contract changes. Custom Threat Feed synchronization, scheduling, queue, confidence, expiration, deduplication, and IOC source attribution semantics are unchanged.
- No dependency version changes.

## Validation

- Backend: VirusTotal metadata, File Information, enrichment-aggregation, and MCP IOC test suites pass; a new integration-level regression covers the VirusTotal → IOC-detail File Information flow (SHA256-only IOC + persisted VT enrichment → hashes/type/MIME populated, existing values and source preserved, no new IOC records).
- Frontend: full test suite passes (including new IOC-link and Custom Threat Feeds view helpers); production build succeeds.

## Notes

- This is a beta prerelease.
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.10`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
