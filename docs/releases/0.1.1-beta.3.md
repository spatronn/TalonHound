# TalonHound v0.1.1-beta.3

This beta adds a user-specific IOC Watchlist and fixes the "Open in VirusTotal" links.

## What's New

### IOC Watchlist

- Added a user-specific IOC Watchlist.
- Users can star/unstar IOCs to manage their own Watchlist.
- Watchlist membership is isolated per user; one user's stars are never visible to another.

## Fixes

### VirusTotal

- Fixed "Open in VirusTotal" links.
- VirusTotal enrichment links now open the corresponding VirusTotal GUI page (`https://www.virustotal.com/gui/...`) instead of the `/api/v3` endpoint.
- IOC-type-aware mapping covers URL, domain, IPv4/IPv6, and file-hash observables; legacy cached rows self-heal on read.

## Notes

- This is a beta prerelease.
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.
- Migration 017 introduces the per-user watchlist table.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.3`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
