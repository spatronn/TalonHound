# TalonHound v0.1.1-beta.4

This beta introduces the TalonHound **MCP Server**, so AI clients can look up and import IOCs against your live inventory over Streamable HTTP.

## What's New

### MCP Server

- Streamable HTTP endpoint at `/mcp` with Bearer authentication (`th_mcp_` API keys).
- Access profiles **MCP Read** (`mcp_read`) and **MCP Analyst** (`mcp_analyst`), each bound to an owner user.
- Effective rights are the intersection of token scopes and the owner user’s RBAC role.
- Tools: `lookup_ioc`, `search_iocs`, `get_ioc_context`, `bulk_lookup_iocs`, `list_ioc_sources`, `import_iocs` (with `dry_run`).
- Imports reuse existing IOC Sources and the same manual ingestion path as the GUI — no special “MCP Source”.
- Rate limits, batch caps, and audit actions `mcp.tool_call` / `mcp.ioc_import` (`source` / channel `mcp`).
- Operator guide: [`docs/MCP.md`](../MCP.md).

## Notes

- This is a beta prerelease.
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.
- Migration **018** adds MCP scopes, `mcp_read` / `mcp_analyst` key types, and `owner_user_id` on API keys.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.4`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
