# TalonHound v0.1.0-beta.2

This beta focuses on Published Feeds performance and I/O efficiency.

## Performance

- Reduced unnecessary Published Feeds database writes.
- Added IOC-type-scoped dirty polling so feeds no longer scan unrelated IOC churn.
- Optimized projection reconciliation to use index-friendly bucket lookups.
- Added cached projection item counts to eliminate repeated large `COUNT(*)` operations.
- Optimized chunk reuse checks to avoid expensive complement scans.

## Production Validation

Observed PostgreSQL write I/O during production validation decreased from approximately:

~7.5 GB/hour

to:

~0.43 GB/hour

during the measured workload window.

## Reliability

- Published Feed projection behavior remains verified during full rebuilds.
- Migration 016 introduces/backfills projection item counts.
- Relevant Published Feeds regression suite passes.

## Notes

TalonHound remains in beta.
Further read-I/O profiling and optimization will continue during the beta period.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.0-beta.2`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
