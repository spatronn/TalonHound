# TalonHound v0.1.1-beta.9

Runtime beta upgrading the entire TalonHound stack from Node.js 20 (end-of-life) to the Node.js 24 LTS line.

## Changed

- Upgraded all Node.js runtime and build environments to Node.js 24 LTS (`node:24-alpine`):
  - Backend API and all backend workers (IOC expiration, search export, deep search, bulk query, backup).
  - Integration scheduler and worker (previously Node 22).
  - Frontend production build stage (runtime remains nginx).
- Updated CI/release workflows and the host/baseline validation scripts to Node 24.
- Declared `engines.node` `">=24 <25"` in the backend, frontend, and integration packages to codify the supported LTS runtime.

## Compatibility

- **No database migration required.** No schema or data changes.
- No dependency version changes were required for Node 24; `bcrypt` compiles cleanly under Node 24, and crypto/TLS APIs in use are stable.
- No API contract changes.
- Custom CA / outbound HTTPS (feeds, enrichment providers, MCP) verified under Node 24 / OpenSSL 3.5.7.

## Validation

- Clean (`--no-cache`) Docker builds of all Node-based images; containers report Node 24.20.0.
- Backend, frontend (671 tests), and integration/worker test suites pass under Node 24; MCP regression suite (lookup_ioc, bulk_lookup_iocs, get_ioc_context, hash handling, classification consistency) passes.
- Full-stack boot with no crash loops, native-module failures, or TLS/OpenSSL errors.

## Notes

- This is a beta prerelease.
- Existing TalonHound beta users can upgrade using the project's supported upgrade mechanism.

## Install and upgrade

- Fresh install: `sudo ./installation.sh`
- Upgrade: `sudo ./installation.sh --upgrade` (or `--upgrade-to 0.1.1-beta.9`)
- Official images and digests are recorded in `release-manifest.json`

See `docs/deployment.md` and `docs/upgrade.md`.
