Hardening CI runners against supply-chain abuse

By Vendor Security Research

view all posts by this author

This guidance article explains how to harden continuous integration runners. It discusses npm lifecycle scripts, credential scoping, and cache hygiene. No formal indicators of compromise are published here.

Recommended controls

Pin dependencies, disable unexpected lifecycle scripts in CI, and rotate tokens from a known-clean administrator workstation. References to the public package registry and the source-control forge describe platforms, not attacker infrastructure.

Example hunting idea

DeviceProcessEvents
| where FileName =~ "node.exe"
| where ProcessCommandLine has "preinstall"

Operators should treat this as defensive documentation only.
