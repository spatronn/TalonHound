ChainDrop supply chain compromise: Anatomy of a self-propagating worm

By Vendor Security Research

view all posts by this author

, Alice Analyst

view all posts by this author

Vendor Threat Intelligence identified a large-scale npm supply chain attack affecting more than 400 packages. The malicious releases contain a self-propagating credential-stealing worm delivered through an obfuscated Bun-based JavaScript payload that executes via an npm preinstall lifecycle hook.

Attack chain overview

The campaign appeared as unauthorized patch releases. Operators used stolen maintainer credentials and later propagated with npm publishing tokens. Narrative mentions of github.com and registry.npmjs.org are platform context, not publisher-asserted Indicators.

Mitigation and protection guidance

Organizations should rotate credentials from a known-clean environment and rebuild affected systems from trusted sources.

Indicators of compromise (IOC)

Advanced hunting queries

Defenders can run the following hunting query. These code snippets are detections, not an IOC table:

DeviceFileEvents
| where Timestamp > ago(3d)
| where SHA256 in~ ("54dc7ea54a1317cca0e890a2770630cf7fa6c97813e0cb9d2caa93012b350668")
