Backdoor hides command traffic in cloud collaboration APIs

The backdoor authenticates against a cloud tenant controlled by the operators and exchanges tasks through calendar and mail objects.

Microsoft-hosted services for C2

The malware validates its access token with a request to the tenant endpoint:

GET https://graph.microsoft.com/v1.0/organization
Authorization: Bearer <token>

Tasks are then read from the operator mailbox through https://graph.microsoft.com/v1.0/me/messages and results are uploaded as attachments.

Conclusion

Abuse of legitimate cloud APIs makes network blocking of the API hosts impractical; hunt for the operator tenant instead.
